# Quinto minijuego: El Juego Miente

- **Fecha:** 20 de octubre de 2026
- **Herramienta:** Claude Code (Claude, de Anthropic)
- **Commit o PR relacionado:** `3e5ca8a` y `fe55caa`, PR #56

## Qué necesitábamos

Un minijuego de un estilo distinto a los que ya teníamos (disparos, defensa y lucha).

## El prompt

```
El juego miente: un juego de reacción en el que las instrucciones a veces mienten. Sale «PULSA ROJO» escrito en azul, y la regla cambia cada pocos segundos (obedece al color, obedece a la palabra, haz lo contrario). Engancha mucho y es muy de retar a amigos.
```

## Qué hicimos con la respuesta

- **Aceptado:** el juego completo con récords, clasificación y página propia para buscadores.
- **Cambiado por nosotros:** pedimos el título de la miniatura también en inglés.
- **Descartado y por qué:** las otras ideas de minijuego (puzle, carreras, ritmo): elegimos la más original.
