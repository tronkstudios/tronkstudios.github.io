# Prompts clave

Aquí guardamos las órdenes más importantes que le dimos a la IA mientras
hacíamos la web: las que cambiaron cómo está montada, no cada pregunta pequeña.

Un archivo por tema, con este formato (copia `plantilla.md`):

- `01-backend-soporte.md`: cómo pedimos el Cloudflare Worker del soporte.
- `02-seguridad-csp.md`: la política de seguridad y por qué.
- `03-stick-drill-movil.md`: los joysticks táctiles.
- `04-reorganizacion.md`: dividir `script.js` en módulos y documentar.

Lo importante no es solo el prompt, sino **qué hicimos nosotros con la
respuesta**: qué aceptamos, qué cambiamos y qué descartamos.
